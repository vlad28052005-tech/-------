Технічні поля

Коди — внутрішній ідентифікатор групи: саме їх запам'ятовує телефон студента, коли він обирає групу. Для нової групи вони заповнюються самі. У наявної групи краще не змінювати, бо студентам доведеться обрати групу заново.

Менше число — вище у списку.

Час пар

Дзвінки однакові для всіх днів. Прибрати можна лише останню пару.

JSON (імпорт / експорт)

Повний розклад групи у форматі { settings, times, template }. Можна вставити сюди JSON і натиснути «Застосувати».

Видалення групи прибере її розклад у всіх студентів.
